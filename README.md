A 100-word monologue for a fantasy villain who is secretly just very tired: the Ashen Crown, three centuries of squeaks, and a hero shown the door. The tiredness lives in the rhythm and the small chores, never in a plain announcement.

## Run it

OUTPUT_DIR=output python3 main.py
